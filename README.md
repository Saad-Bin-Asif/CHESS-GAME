
# C++ Console Chess Game

## Overview
This is a fully working Chess game made in C++. It runs in the console (terminal). I used Object-Oriented Programming (OOP) to build this project. It has all the main rules of real chess.

## Features
* **OOP Design:** Every chess piece (King, Queen, Rook, Knight, Bishop, Pawn) has its own class.
* **Real Chess Rules:** All pieces move exactly like they do in a real chess game.
* **Path Checking:** Pieces cannot jump over other pieces, except for the Knight.
* **Undo Wrong Moves:** If a player makes a move that puts their own King in danger (Self-Check), the game stops them and undoes the move.
* **Check and Checkmate:** The game tells you when the King is attacked (Check). It also ends the game when a player is defeated (Checkmate).
* **Turn System:** White and Black players take turns one by one.

 **How to Play**
1. Download the code to your computer.
2. Run the C++ code in your compiler.
3. The chess board will show numbers from 0 to 7 for rows and columns.
4. The game will ask for a starting position. Type the Row and Column number of your piece.
5. Then, type the Row and Column number of where you want to move it.
